# CAD & Prototyping Roadmap: Decoupled Bristle-Bot Swarm
**Project:** IPT Problem 11 — Bristle-Bot Swarm in a Maze  
**Architecture:** Standardized Active Drive Core + Interchangeable "Hovering" Collision Hulls

---

## 1. Tool Selection: Why OpenSCAD?
* **Git Native:** Models are `.scad` text scripts, not heavy binary blobs (`.step`, `.f3d`). Code diffs show exact parameter adjustments in commit histories.
* **True Parametric Physics:** Allows automated variable sweeping (`leg_angle`, `wall_clearance`, `hull_type`) without manual re-sketching.
* **Zero License Lock-in:** Open-source, free, lightweight, and cross-platform (Linux/macOS/Windows).

*(Alternative: If visual sketching is preferred, use **Onshape** with a free public education account, but export parametric `.step` files along with documented dimension tables into Git).*

## 3. Modeling Phases & Milestones

### Phase 1: Master the Core OpenSCAD Primitives (Day 1)
* Learn Constructive Solid Geometry (CSG):
  * Primitives: `cube([x, y, z], center=true)`, `cylinder(h=h, r=r, center=true)`.
  * Boolean operations: `union()`, `difference()`, `intersection()`.
  * Transformations: `translate([x, y, z])`, `rotate([rx, ry, rz])`.
* Set `$fn = 60;` at the top of scripts for smooth cylindrical surfaces.

### Phase 2: The Standardized Drive Core (Days 2–3)
* **Goal:** A unified base housing the motor, battery, and 3 slanted legs.
* **Requirements:**
  1. Flat bottom plane with 3 slanted cylindrical legs arranged in a $120^\circ$ tripod at radius $R \approx 8\text{ mm}$.
  2. Central cylindrical cavity for the 10 mm ERM vibration motor.
  3. Upper cradle for the CR1220 battery with wiring pass-through channels.
  4. Flat upper ceiling for the adhesive ArUco tracking tag.
  5. Outer cylindrical collar (Ø 20.0 mm) with a small alignment lip to receive snap-on hulls.

### Phase 3: The Interchangeable "Hovering Hulls" (Days 4–5)
* **Goal:** Outer geometric shells that snap onto the core but hover $1.5\text{ mm}$ above the ground, ensuring only collision cross-section varies.
* **Geometries to generate:**
  1. `hull_circle.stl` (Baseline isotropic disk, Ø 28 mm)
  2. `hull_triangle.stl` (Equilateral triangle with rounded vertices to prevent wedging)
  3. `hull_ellipse.stl` (Anisotropic rod-like particle, aspect ratio 2:1)
  4. `hull_hexagon.stl` (Facetted particle to study flat-face alignment along walls)

### Phase 4: Modular Maze Tiles (Days 6–7)
* Standard corridor width: $W = 50\text{ mm}$ (approx. $1.8\times$ bot diameter).
* Wall height: $H = 20\text{ mm}$, thickness $t = 3\text{ mm}$.
* Tile units:
  * Straight corridor ($100\text{ mm}$)
  * $90^\circ$ elbow corner
  * Symmetric Y-junction vs. T-junction
  * Bottleneck constriction ($50\text{ mm} \to 25\text{ mm}$)

## 4. 3D Printing Protocol (FDM / Prusa / Bambu / Ender)

1. **Print Orientation (Crucial):**
   * **Core:** Print **upside-down** (battery/motor deck flat on the build plate, legs pointing straight up into the air). This eliminates the need for support material on the angled legs.
   * **Hulls:** Print flat on their top rim.
2. **Slicer Settings:**
   * **Layer Height:** 0.16 mm (or 0.20 mm standard).
   * **Infill:** 100% for the core (ensures legs are solid elastic beams without internal air pockets).
   * **Perimeters/Walls:** 3 walls minimum.
   * **Material:** PLA for baseline stiffness. (Keep TPU/flexible filament as a secondary variable if PLA legs slip excessively).

## 5. Ready-to-Run OpenSCAD Starter Script (`core_tripod.scad`)

Save this code into `cad/core_tripod.scad` and open it in OpenSCAD. Press **F5** to preview, **F6** to render, and **F7** to export `.stl`.

```openscad
// ========================================================
// IPT Task 11: Parametric Bristle-Bot Core
// ========================================================

$fn = 60; // Circle smoothness

// --- PARAMETERS (Tweak these for experimental sweeps) ---
core_radius     = 10.0;  // 20 mm base diameter
core_height     = 6.0;   // Main chassis thickness
leg_radius      = 0.75;  // 1.5 mm diameter legs
leg_length      = 7.0;   // Length of elastic pegs
leg_angle       = 15.0;  // Slant angle in degrees
leg_pitch_r     = 7.5;   // Distance of legs from center
motor_d         = 10.4;  // Motor pocket diameter (clearance included)
motor_h         = 2.8;   // Motor pocket depth
battery_d       = 12.8;  // CR1220 battery diameter
battery_h       = 2.2;   // Battery slot depth

module single_leg() {
    // Rotates leg outward/tangentially to generate forward motion
    rotate([0, leg_angle, 0])
        cylinder(r=leg_radius, h=leg_length, center=false);
}

module core_body() {
    difference() {
        // Outer solid core cylinder
        cylinder(r=core_radius, h=core_height, center=false);

        // Motor cavity (from the bottom)
        translate([0, 0, -0.1])
            cylinder(d=motor_d, h=motor_h + 0.1);

        // Battery pocket (from the top)
        translate([0, 0, core_height - battery_h])
            cylinder(d=battery_d, h=battery_h + 0.5);

        // Wiring wireway through-hole
        translate([0, 0, -1])
            cylinder(d=2.0, h=core_height + 2);
            
        // Outer mounting lip for snap-on hovering hulls
        translate([0, 0, core_height - 1.5])
            difference() {
                cylinder(r=core_radius + 1, h=2);
                cylinder(r=core_radius - 1.0, h=2);
            }
    }
}

module assembled_core() {
    // Core body
    translate([0, 0, leg_length * cos(leg_angle)])
        core_body();

    // 3 Leg Tripod (spaced at 0, 120, 240 degrees)
    for (theta = [0, 120, 240]) {
        rotate([0, 0, theta])
            translate([leg_pitch_r, 0, 0])
                single_leg();
    }
}

// Render assembly
assembled_core();
